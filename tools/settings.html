Aircraft settings

Aircraft data only — values that change only if the aircraft changes (new weighing, different aircraft). Per-flight assumptions (wind credit, distance and safety factors, reserves, contingency, power setting) are edited on the pages that use them. Defaults come from the POH, the weight schedule (WS) and the club spreadsheets (XLS); where they disagree the most conservative value is the default. Changes are saved in this browser only and apply to all pages. Changed values are highlighted. Reload other open pages after changing.
